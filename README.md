# AI Data Metrics Agent

Natural Language Data Analysis using:

- Ollama (Llama2)
- Streamlit
- SQLite
- Excel
- CSV

## Installation

```bash
pip install -r requirements.txt
```

## Run Ollama

```bash
ollama serve
```

## Run App

```bash
streamlit run app.py
```

## Example Questions

- What is total revenue?
- Show revenue by region
- Which department has highest salary?
- Show visitor trend
